# Mots fléchés spécial maths

Grille de mots fléchés interactive proposée par **Les maths à Toulouse** (IMT & EUR MINT).

▶ **Jouer** : la page est publiée via GitHub Pages depuis le dépôt IMT (GitHub Pages).

## Contenu
- `index.html` : la grille jouable (page autonome, sans dépendance hormis la police Inter).
- `logos/` : logos du laboratoire affichés en en-tête et en pied de page.

## Ajouter une nouvelle grille
Les mots, définitions et positions sont dans la constante `DATA` en haut du script de `index.html`.
